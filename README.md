## How to Run

1. Extract the project folder.
2. Open `index.html` in a modern web browser.
3. Choose **HTML Programs**, **CSS Programs**, or **JavaScript Programs**.
4. Select any program from the section list.
5. Use the **Home** and section navigation links to move through the project.

No server is required for the basic programs; the project is designed to run by opening the HTML files directly in a browser.
